# 1. Go basics

## Learning goals
Build and run a Go program, use `package` and `import`, declare variables and constants, and explain Go's basic types.

Practice `go version`, `go run .`, `go build .`, and `go fmt ./...`.

## Mission
Create `greeter`: store a name and age, print a greeting, and calculate the age next year.

## Think
Why does Go reject unused imports and local variables?
