# 8. Testing

Testing is part of the standard Go toolchain.

Learn `TestXxx`, table-driven tests, subtests, benchmarks, and coverage.

Run `go test ./...`, `go test -cover ./...`, and `go test -bench=. ./...`.

## Mission
Write table tests for `ParsePort`, covering boundaries and invalid input.

From this point onward, course projects should test logic that can reasonably be checked automatically.
