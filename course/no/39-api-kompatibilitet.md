# 39. API-kompatibilitet

Et offentlig Go-API er en kontrakt med brukerne.

Lær hvordan eksporterte navn, funksjonssignaturer, interfaces og struct-felt påvirker kompatibilitet. Foretrekk små API-er og gjør endringer bevisst.

## Oppdrag
Design v1 av en liten pakke, skriv klientkode og vurder hvilke endringer som kan gjøres uten å bryte klienten.
