# 93. internal og offentlig API

Go håndhever importgrenser for kataloger under `internal/`. Bruk dette til å holde implementasjonsdetaljer private mens stabile inngangspunkter forblir små.

## Oppdrag
Flytt en implementasjonsdetalj bak `internal/` og dokumenter hvilken del som faktisk er ment som offentlig kontrakt.
