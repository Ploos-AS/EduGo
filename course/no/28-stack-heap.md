# 28. Stack, heap og escape analysis

Go bestemmer lagring ut fra programmets behov, ikke bare syntaksen.

Bruk kompilatorens diagnostikk for å undersøke escape analysis og benchmarks for å måle allokeringer.

## Oppdrag
Lag små funksjoner som returnerer verdier og pekere. Undersøk hva kompilatoren rapporterer, men skill mellom observerte compiler-valg og språkgarantier.

Målet er forståelse, ikke å "bekjempe heapen" overalt.
