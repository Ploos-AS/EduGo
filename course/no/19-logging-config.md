# 19. Logging og konfigurasjon

## Læringsmål
Bruk strukturert logging med `log/slog`. Les enkel konfigurasjon fra flagg og miljøvariabler. Valider konfigurasjonen før programmet starter hovedarbeidet.

## Oppdrag
Utvid M3-tjenesten med `PORT`, `LOG_LEVEL` og CLI-overstyring.

## Prinsipp
Ikke logg hemmeligheter. Skill maskinlesbare logger fra brukerrettet CLI-output.
