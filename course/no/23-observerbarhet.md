# 23. Observerbarhet og slog

Bruk `log/slog` for strukturerte logger og request-kontekst for nyttige felt.

## Oppdrag
Logg metode, sti, status, varighet og request-ID for hver HTTP-request. Ikke logg hemmeligheter eller hele request bodies ukritisk.

Skill mellom logger, metrics og tracing som forskjellige signaler. Dette kapitlet fokuserer på logging og måling i egen prosess.
