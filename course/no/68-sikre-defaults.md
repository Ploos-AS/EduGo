# 68. Sikre defaults

Sikkerhet starter med grenser og forutsigbar oppførsel.

Sett eksplisitte størrelsesgrenser, timeouts og tillatte verdier. Avvis tvetydig eller ugyldig input tidlig, og ikke gjør en usikker fallback når sikker konfigurasjon feiler.

## Oppdrag
Gå gjennom noteservice og identifiser hvilke ressurser en klient kan få tjenesten til å bruke.
