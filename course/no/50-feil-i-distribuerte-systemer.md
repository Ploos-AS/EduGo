# 50. Feil i distribuerte systemer

Nettverk kan være trege, forbindelser kan brytes, svar kan forsvinne og en klient kan være usikker på om en operasjon ble utført.

## Oppdrag
Klassifiser timeout, connection refused, 500, 429 og ugyldig respons. Bestem hvilke som kan retries og under hvilke forutsetninger.

Unngå å redusere alle feil til «nettverket er nede».
