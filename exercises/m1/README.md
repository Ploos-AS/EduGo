# M1 exercises

1. **greeter** — variables, constants, formatting and arithmetic.
2. **fizzbuzz** — control flow and functions.
3. **wordcount** — slices, strings and maps.
4. **readers** — structs, methods and interfaces.

For every exercise:

- run `gofmt`;
- build without warnings/errors;
- add table-driven tests where the task contains logic;
- try at least one input beyond the happy path.

Solutions belong in a separate solutions area so students can work without accidentally reading them.
