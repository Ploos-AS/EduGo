# M4 — Production Go

M4 focuses on operating software safely and predictably.

1. Process lifecycle and graceful shutdown
2. Timeouts, deadlines, and input bounds
3. Explicit dependencies and testable design
4. Structured logging and observability
5. Benchmarks and profiling
6. Fuzzing
7. Cross-compilation and distribution

## Completion gate

Students should be able to explain not only how a service starts, but how it stops; not only that it is fast, but how performance was measured; and not only that ordinary tests pass, but what fuzzing and the race detector add.
